DEMO PLAN / NOT YET PUBLISHED

What the demo will show

  1. Use a fictional application's signup or request form and follow a written test checklist.
  2. Submit valid, empty and invalid values, then show a reproducible defect.
  3. Write a concise report with evidence and an explanation of its impact.
  4. Retest a corrected version and record the result.

How results will be checked

A sample test plan, bug report and retest record will make the testing process inspectable. A clean test run does not guarantee an application is bug-free.

Demo format

A short recording with fictional data, screenshots or sample output, and relevant documentation. Source code or sample reports will be linked when ready. No live demo is currently published here.

Case study
