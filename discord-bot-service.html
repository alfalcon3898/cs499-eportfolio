Before you choose

A few helpful answers.

Is this an AI chatbot?

This package returns the exact text configured for each command. It is ideal for consistent answers to known questions. AI-generated conversations would be a separate project.

Will it stay online all the time?

The Python program needs to keep running on your computer or a hosting service. Hosting is not included in the $99 package. We agree on where it will run before starting.

What do I need to provide?

Your approved commands and reply text, a Discord server where you can add a bot, and your own Discord application. The walkthrough explains local token setup; keep credentials private.

Can I change the replies later?

Yes. Edit the supplied JSON configuration file, save it and restart the bot. Setup instructions explain the file format and common mistakes.

Does it work on other chat platforms?

The demonstrated package is for Discord. Slack, Telegram, website chat and other integrations need separate development and testing.

When will it be delivered?

The delivery date is agreed after reviewing your command list and setup. This page does not take payments or automatically book a delivery slot.
