DEMO PLAN / NOT YET PUBLISHED

What the demo will show

See how a community member would interact with a custom bot, starting with one small command and growing into a configurable AI personality.

Example walkthrough

  1. Send the planned !debug command and see a fixed, playful response in a demonstration server.
  2. After AI integration, submit sample messages and compare replies using the configured personality.
  3. Repeat a command too quickly to demonstrate a cooldown, then show how usage limits prevent unlimited API calls.
  4. Simulate an unavailable AI provider and demonstrate a helpful failure response rather than a crashed bot.

How the results will be checked

The demo will show configuration choices, command behavior and selected automated tests. A funny reply alone will not be presented as evidence of reliability.

Demo format

A short recording in a dedicated test server, plus setup instructions and sample commands. A public always-on bot is not yet available.
