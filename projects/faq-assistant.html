PLANNED SERVICE SCOPE

What I would provide

Restaurants and small businesses answering repeated questions.

This describes a future offer being developed through this project. Deliverables will be confirmed for each engagement once the relevant capability is demonstrated.

Planned deliverables

  • Answers based on a supplied and approved set of business information.
  • A defined topic scope, such as opening hours, menu questions and contact details.
  • An unknown-answer response and a contact or handoff option.
  • A simple API or website widget as agreed, with answer evaluations and update instructions.

Handoff & support

The intended handoff includes the agreed source code or configuration, setup instructions, a short demonstration and acceptance checks. Before a project starts, we would agree on required access, delivery milestones, revision limits and a defined support window.

Hosting and third-party API accounts, usage charges and ongoing maintenance would be agreed explicitly.

Possible additions

Booking, ordering, payments, multilingual support and connections to live business systems would require separate scope.

Current progress

No demo has been built yet. The initial scope will cover fictional restaurant hours and menu questions.

Planned milestones

  1. Approved information and unknown-question handling
  2. A small API and optional chat interface
  3. Repeatable answer evaluations
